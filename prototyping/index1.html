Key Annotations features + reading order
Key features · 1–5
  1. 1
    Scan-first result cards

    Photo, material, quantity, condition, broad area and price, so buyers can shortlist without opening every listing.

  2. 2
    Inspect-first listing detail

    Condition, quantity, unit, asking price, seller permission and a clear statement that the exact address stays hidden.

  3. 3
    Quick questions + inspection slot

    One-tap questions lower the effort of contacting a seller; date and time turn chat into a real inspection plan.

  4. 4
    Collection agreement tracker

    Agreed quantity, collection window, price plus transport, and a visible path from Contacted to Collected.

  5. 5
    Seller permission check

    The seller confirms they may sell the material and submits for review before the listing can be published.

Intended user flow

Buyer: Browse → Listing detail → Contact → Collection. A request sent from Contact appears in the seller’s Incoming requests; an accepted request returns the buyer to Collection.

Seller: Create listing → My listings (review + status) → Incoming requests (accept or suggest another time).

Exceptions: no results leads to State A; a suspicious listing leads to State B, the moderator report form.
